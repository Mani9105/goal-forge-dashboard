# Goal Forge Dashboard

Build a modern AI agent web app called GoalForge. User enters a real-world goal. Create a clean dashboard with Goal Input, Plan, Agent Activity, Tasks, Approval Requests, and Final Result. Use mock data. Frontend only; no AI/backend logic.
